## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/ChainGlen.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure ChainGlen, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
